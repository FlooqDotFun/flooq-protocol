Was the “qubit” ending chosen?
No. The bits came from the quantum job, and the ending came from a public counter search: n is the smallest counter, from 0, that makes the address end in “qubit”. Anyone can rerun the search.
How do I know the bits came from an IBM quantum computer?
Our server reads the job from IBM's API with a read-only key and shows it live, next to a comparison with the published bits. Doubt it? We'll re-run a fresh job live on an X Space.
What is QUBIT Vault?
A Solana vault locked by a hash instead of a public key. Each withdrawal is signed with a fresh one-time key (WOTS+ over SHA-256), then the vault locks itself to the next key. You use it with the qubit command-line tool.
Can the vault program change?
No. It has no upgrade authority, and its code on mainnet matches a reproducible build of the open-source repository.

Born from a quantum computer.
A bit is a switch.
Every computer you have used stores information in bits. A bit is 0 or 1, nothing in between.
A qubit is an arrow.
A qubit can point anywhere on a sphere. Straight up reads 0, straight down reads 1. Every other direction is a superposition: part 0, part 1.
One gate puts it on the fence.
The Hadamard gate turns a qubit that reads 0 into an even mix of 0 and 1. QUBIT's job applied it to each of 16 qubits.
Measuring makes it choose.
Read a qubit in that state and you get 0 or 1, each half the time. No program picks the answer. Sixteen qubits give one of 65,536 possible strings per shot.
Inside the machine.
IBM's qubits are superconducting circuits on a chip. A golden, multi-tiered refrigerator holds the chip at about a hundredth of a degree above absolute zero, colder than outer space.
